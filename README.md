## LESSON 1- Variables

**Variables** are like containers which store information. A variable is defined by its **name**, **value** and **data-type**. A variable can store **ANY** type of data such as string or integer. A variables value can also **change**!

*Input* is any data that is **external** from the code written. input would be used for times when you need data that is **different** for **different** users. For example when you log in you input a password.

*Print* is any data that is **sent** externally from the running code out to the user, *Print* would be used for times when you need to show data is different based on the codes results or the **users actions**. For example when you log in it prints "Welcome User!".

## Lesson 2- Data Types & string-manipulation

**Data types** are labels for your data, if a variable is a container a data type tells python **exactly what kind of item** is inside.

**Strings** represent **text**, *input* naturally defaults to string, this  is the data type the human mind understands best.

**String manipulation** is essentially **Python literacy**. You will use it in every project, just like writing explanatory notes in a math assignment.

**Integers** represent **whole numbers**. They are the foundation for any basic mathematical operation.

**Floats** represent **decimal numbers**. They are used for precise mathematical operations and tracking measurements like distance or temperature.

**Booleans** represent **true** or **false**. Think of boolean as a **fork in the road**. One of two choices leading to a different result.

**None** represents the **absence of data**. It is a placeholder for a value you dont know yet. Like your test score before the results are released.
