LESSON 1- Variables

Variables are like containers which store information. A variable is defined by its name, value and data-type. A variable can store ANY type of data such as string or integer. A variables value can also change!

Input is any data that is external from the code written. input would be used for times when you need data that is different for different users. For example when you log in you input a password.
